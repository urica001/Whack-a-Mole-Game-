# Whack‑a‑Mole Game｜打地鼠小游戏

> A simple 5×5 whack‑a‑mole desktop game built by Python‑Tkinter.
> 基于Python Tkinter开发的5×5打地鼠桌面小游戏。

## 📖 Introduction｜项目简介
- The mole stays at a fixed random position when the game starts.
  开局地鼠随机固定一个位置，不会移动。
- Player has 5 chances to find the mole.
  玩家拥有5次点击机会寻找地鼠。
- Click feedback: Hit / Nearby / Miss.
  点击反馈：命中获胜、邻近提示、未命中。
- Auto‑reveal mole position when out of attempts.
  机会用尽自动公布地鼠位置。
- One‑click restart, no third‑party packages required.
  一键重开，无需安装第三方库，使用Python内置库。

## ⚙️ Environment｜运行环境
- Python ≥3.8
- Tkinter (Built‑in in Python)

## 🚀 How to run｜运行方式
```bash
python main.py
